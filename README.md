# 阅读手表版

一款专为圆屏手表设计的离线 TXT 阅读器。

## 怎么用

1. 把 txt 小说文件传到手表的 **Download** 文件夹
2. 打开「阅读手表版」
3. 书架会自动扫描并导入 txt 文件
4. 点击书本开始阅读

## 阅读操作

| 操作 | 效果 |
|------|------|
| 点击屏幕右侧 | 翻到下一页 |
| 点击屏幕左侧 | 翻到上一页 |
| 点击屏幕中间 | 打开阅读菜单 |
| 从左边缘向右滑 | 退出应用（首页）/ 返回 |

阅读菜单里可以调字号、调亮度、查看目录。

## 适配设备

- OPPO Watch X（466×466 圆屏）
- 其他 Wear OS 圆屏手表理论上也能用

## 安装

```bash
adb install legado_app_1.0.0.apk
```

## 特点

- **完全离线**：不需要联网，没有网络权限
- **自动导入**：扫描 Download 文件夹，txt 文件自动进书架
- **圆屏适配**：内容不溢出表盘边缘
- **省电**：OLED 黑底背景
